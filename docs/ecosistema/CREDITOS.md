# Rikuy — Créditos y procedencia

> Lista de cada idea o pieza de código que Rikuy toma de otros proyectos. El equipo declara que la reutilización de código de otros equipos de hackathon está permitida; aun así, **ningún repositorio de Hack the Andes revisado incluye archivo LICENSE** (Yaku y GiomarDev declaran `"license": "UNLICENSED"` en `package.json`). Por eso: (1) cada pieza se acredita aquí y en el archivo donde se use; (2) se pide a cada autor un OK escrito de una línea antes de copiar código; (3) si no llega, se reimplementa la idea sin copiar.
> Tipo: **Código** (se copia o adapta código) · **Patrón** (se reimplementa la idea) · **Datos**.
